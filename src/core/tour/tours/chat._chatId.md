# Chat

## .messageList
Replies land here. Hover a message for its edit, retry and delete buttons.

## .composer
Type here and press Enter to send. Shift+Enter starts a new line.

## .composerControls
The send button, and the controls for continuing or regenerating the last reply.

## .chatToolbar
Chat-level actions: renaming, exporting, and deleting a range of messages.

## .sidebar | right | desktop
The rail holds this chat's settings while it's open: the connection, the persona, the prompt stack
and the lorebooks in play.

Closing the chat puts the module links back.
