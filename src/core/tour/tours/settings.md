# Settings

## .pageTabs
Settings are split across these tabs. Connections is the one to start with.

## .connectionList
A connection is an endpoint, a key and a model. Nothing sends until one exists.

## .connectionActions
Add a connection here. The key is stored in this browser and goes only to the endpoint you name.

## .debugToggle
Debug mode adds the prompt inspector to a chat. It shows what was actually sent.
