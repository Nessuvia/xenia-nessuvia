Xenia Nessuvia

A character chat and long-form writing app that runs entirely in your browser. No install, no account, no server of ours holding your data.

Open the app

What it is

Xenia Nessuvia is a static web app. It loads once and runs in your browser like any other page. You bring an API key for any OpenAI-compatible model endpoint, and the app talks to it directly, nothing routes through us, and no database of ours stores your characters, chats, or stories. The source is GPL v3.

Chat

Imports TavernV2 character cards, or build one in the editor. Alternate greetings and swipes work as expected. Each character can carry its own text color, so a multi-character chat stays readable at a glance. Characters can carry a gallery of linked images beyond the main avatar. World info entries trigger on keywords in the conversation and inject their text into the prompt when they match. Lorebook control is intentionally simple today.

Write

Write is the long-form counterpart to Chat. Instead of back-and-forth, you build chapters from beats with word targets. It shares characters and world info with Chat, but the structure underneath is its own thing.

Multiplayer

The host starts a session and shares a link. Guests join with a persona, no install, no account. Turn order is rearrangeable. A narrator role answers when no character present should. Only the host holds an API key, and only the host talks to the model.

Ask

One question to the model, outside any chat. Optionally load a character to answer as. Handy for quick things.

Prompts

Prompt content is built from reusable, rearrangeable blocks. Blocks support XML-style tagging. One block type is a scroll: a single number, like a target word count, adjusted directly without opening the block. A live prompt preview shows the assembled text before it is sent, and Chat includes a raw request inspector so you can see the exact payload reaching the endpoint.

Palette

Appearance is its own system: built-in webfont loading, app-wide color palettes, panel styling, plus scoped custom CSS and HTML for backgrounds. Custom CSS is wrapped in @scope so it can't leak into the rest of the app.

Models and settings

Endpoints
Any OpenAI-compatible endpoint, hosted or on localhost. Chat completion and text completion both work.
Samplers
Sampler parameters are rows of data. Add one by hand for a backend-specific parameter Xenia doesn't already list, and it appears in the UI. That includes local-backend samplers like Mirostat, Min-P, DRY, or quadratic sampling without waiting for a release.
Import and export
One JSON file holds characters, chats, stories, and settings. Load it on another machine and you're back where you left off. API keys and bucket credentials are stripped before the file is written.

Where data goes

Characters, chats, stories, and settings live in your browser's IndexedDB. Four things leave the tab, and nothing else:

  • Model requests go to the endpoint you configure, with your API key.
  • Multiplayer messages pass through a relay (Supabase Realtime, or a self-hosted Centrifugo instance) that stores nothing and never sees API keys.
  • Sync, if turned on, writes to an S3-compatible bucket you own.
  • A tokenizer vocabulary downloads from jsDelivr when requested, with no user text sent.

Requirements

A modern browser and an API key for an OpenAI-compatible endpoint. That's it. The app works as a PWA, so you can add it to your home screen or desktop if you want.

Status

Free, no signup. Actively developed and used daily by its author. Source at github.com/nessuvia/xenia-nessuvia.
